<h2>一、下单前必须定的四件事</h2>
<p>这四件事没定，后面所有时间都会被拖长。定完了再点支付，能省掉一轮返工。</p>
<h3>第一件：按人还是按号分配</h3>
<p>团队协作按人分配，一人一条，交接清楚；多账号运营按号分配，一号一条，关联面最小。两种都行，但必须在付款前定，因为按号分配往往要一次买多条，规格和报价都不一样。</p>
<h3>第二件：计费口径与结算周期</h3>
<p>一个月的套餐是自然月还是三十天，从哪天起算，中途开通怎么折算。这些细节决定你实际能用多少天。按自然月算的，月底下单等于只买到几天，最好等月初。</p>
<h3>第三件：要不要独享与白名单</h3>
<p>独享决定能不能多人同时用而不互相挤；白名单决定哪些来源地址能连进来。两样都是加价项，也都是一次配置长期受益的项。团队超过三人，独享基本是必需的。</p>

<h2>二、开通时效：三种交付方式差多久</h2>
<p>宣传页上的"即开即用"通常指订单状态，不等于地址可用。真正的时效要看交付方式。</p>
<h3>接口自动交付：几分钟到半小时</h3>
<p>下单后系统自动分配地址，接口立刻返回四元组。这一种最快，但地址是预先池化好的，刚分配出来可能还没在目标服务那边"热"起来，建议先做一次登录测试再放量。</p>
<h3>人工配置交付：两小时到一天</h3>
<p>需要人工绑定地区、配置白名单、开通端口。工作时段内通常两小时内完成，下班后下单会顺延到次日。着急用就选工作日上午下单。</p>
<h3>定制地区或定制段：三到七个工作日</h3>
<p>指定城市、指定运营商、整段独享这类需求，需要从存量里调资源，周期最长。这类订单一定要在合同里写明交付日期和逾期处理，口头承诺在排期紧张时最不管用。</p>

<h2>三、能不能直接拿去登录：三道自检</h2>
<p>地址到手不等于能用。三道检查过了，再去登正式账号。</p>
<h3>第一道：地址归属对不对</h3>
<p>whois 查 ASN 和运营商名称，确认是住宅宽带运营商，且国家和你买的一致。这一步花两分钟，能挡掉大部分发错地区的情况。</p>
<h3>第二道：环境属性是否自洽</h3>
<p>时区、语言、WebRTC 暴露的局域网段，三项要和出口归属地对上。出口在德国就把时区设成中欧时间、语言设成 de-DE。这一项最容易被忽略，也最容易被平台的时间线看出来。</p>
<h3>第三道：拿小号试一次</h3>
<p>别用主力账号做第一次登录。拿一个不重要的号或新注册的号试，看是否顺畅进入、有没有额外验证、页面是否完整加载。这一步过了，再把主力号迁过来。</p>

<h2>四、异常跟进：把"专人跟进"写成条款</h2>
<p>"后续异常有专人跟进"这句话很动人，但如果没有响应时限和补偿口径，它就只是一句话。</p>
<h3>要问的三个数</h3>
<p>响应时间：工作时段内的首次回复时限，常见是两小时。处理时限：掉线后多久恢复或换新，常见是四到二十四小时。补偿口径：停机超过多久按天顺延，超时怎么算。三个数都要白纸黑字。</p>
<h3>自己也要留一手</h3>
<p>备用线路是成本最低的保险。按主线数量的两成准备备份，平时每周用一次保持可用。真出问题时，切到备用线只要几十秒，等供应商处理可能要几小时。</p>

<h2>常见问答</h2>
<h3>下单当天能拿到能用的线路吗？</h3>
<p>答：接口自动分配的方式通常可以，几十分钟内拿到地址并完成自检。人工配置和指定地区的订单一般要等到次个工作日。如果时间紧，下单前先问清交付方式，而不是先付款再问。</p>
<h3>一个月的套餐从哪天开始算？</h3>
<p>答：按自然月算的从开通日所在月的 1 号起，月底开通等于损失大半月；按三十天算的从开通时刻起算。下单前问清这一句，能避免"明明买了一个月，只用了十天"的落差。</p>
<h3>地址到手后必须先做哪些检查？</h3>
<p>答：查 ASN 归属、交叉核对类型标签、把小号试登一次，三步合计不到十分钟。跳过这三步直接上主力号，等于拿账号去替供应商测试，代价太高。</p>
<h3>线路出问题找谁，多久能解决？</h3>
<p>答：找签约时指定的对接人，同时提工单留痕。合同里写清首次响应与恢复时限，超时按天顺延。手上常备两成备用线路，切换只要几十秒，比等回复快得多。</p>
